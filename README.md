# 洛谷 P17511 [入门赛 #52] 月饼调配 解题报告

## 📌 题目链接与难度
- 链接：[P17511 [入门赛 #52] 月饼调配](https://www.luogu.com.cn/problem/P17511)
- 难度：普及- / 入门

## 📖 题目大意
在一棵树上，每个节点有初始值 `s[i]` 和目标值 `t[i]`。需要将子节点的值通过带权边传递给父节点，求最少操作次数。

## 🧠 解题思路
这道题的常规做法是 DFS 树形 DP，但我没有沿用该思路，而是独创了**反向建图 + 魔改拓扑排序**的解法。

**为什么能用拓扑排序？**
因为操作是自底向上传递的（叶子 -> 根节点）。叶子节点只有出度没有入度，我们可以把每个节点看作图上的点，计算每个节点的出度。将出度为 0 的叶子节点先入队，一层层向上剥洋葱。当处理完一个节点后，将其父节点的出度减 1，如果父节点出度减为 0，则入队。

**为什么能保证最优？**
当前节点的值 `s[v]` 必须变成 `t[v]`，所需的操作次数固定为 `abs(s[v] - t[v]) / w`（向上取整）。多余的差值只能反哺给父节点，这个反哺的差值对父节点来说是强制的，所以不存在多种选择，直接贪心向上传递即可。

## ⏱ 复杂度分析
- **时间复杂度**：O(n)，每个节点仅入队出队一次，遍历所有边一次。
- **空间复杂度**：O(n)，邻接表存图。

## 🛠 踩坑与反思
1. 第一次提交时，因为父节点在队列中入度变更逻辑有误，导致 TLE。
2. 修正后明白：拓扑排序不仅仅是依赖图上的排法，任何具有“叶子剥离”性质的 DAG 都能使用。
3. 教训：比赛时遇到树形结构，不一定非写递归 DFS（容易爆栈），反向思维剥离叶子节点往往更稳健。
